Carpeta `models/checkpoints/` contiene los checkpoints entrenados y su metadata.

Nombres recomendados:
- `aasist_pretrained_asvspoof2019.pth`
- `aasist_ft_siri_eleven_v1.pth`
- `aasist_ft_siri_eleven_v1_config.yaml`

Cada checkpoint debe acompañarse de un archivo `_config.yaml` con hiperparámetros, dataset y commit.
